# ダービーアーケード

メダルで馬券（単勝〜3連単・ボックス・流し・フォーメーション）を買って、ナイターのレースを実況つきで観戦する、メダル競馬アーケードゲームです。馬・騎手・競馬場・レース名はすべて架空です。

## 遊ぶ

- ブラウザで開く：https://togasawara213-droid.github.io/derby-arcade/
- **iPhone のホーム画面に入れる**：Safari で上の URL を開く → 下の「共有」ボタン → 「ホーム画面に追加」 → 「追加」。ホーム画面のアイコンから起動すると、Safari の枠なしの全画面で遊べます（一度開けばオフラインでも動きます）。
- セーブデータは端末（とブラウザ）ごとに保存されます。

## ファイル

- `index.html` … ゲーム本体（1 ファイル）
- `manifest.webmanifest`・`icon-*.png`・`maskable-512.png` … ホーム画面用のアプリ名とアイコン
- `sw.js` … オフラインで遊ぶための Service Worker
